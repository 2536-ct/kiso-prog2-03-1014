## VS Code での進め方

1. `git pull` で最新のファイルを取り込む（未保存の変更がある場合は先に保護する）。
2. `01-binary-literal.c` から順番に開き、`TODO` を検索する。
3. 結果を予想してコードを修正し、コンパイルして動作を確かめる。
4. 【やってみよう】の追加課題にも挑戦する。

```sh
cc -Wall -Wextra -std=c11 -o 01-binary-literal 01-binary-literal.c
./01-binary-literal
```

別の問題ではファイル名を読み替えて実行してください。**未完成の状態でもコンパイルできますが、目標の出力にはなりません。**

## 注意

- `0b` で始まる2進数リテラルは gcc・clang で利用できます。C言語の標準仕様としてはC23から導入されました。
- `04-sign-check.c` の `%hhd` は1バイトの符号付き整数を読み込むための指定です。
- `07-shift-right.c` の負の整数に対する右シフト結果は処理系によって異なる場合があります。
- `05-negate.c` の最小の `int` 値は、同じ `int` 型では正負を逆転できません。
