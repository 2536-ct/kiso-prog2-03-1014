# 基礎プログラミングⅡ 後期第3回 デモコード

2026-10-14の授業で使うコードです。

**使い方：** 各ファイルの先頭に【種類】【内容】【まずやること】【やってみよう】が書いてあります。そのまま実行するだけでなく、**値を変える → 結果を予想する → 実行して確かめる** を繰り返してください。
「練習」「予備」のファイルは、`/* ここを書き換える */` の部分を自分で書いて完成させます。

## ファイル

| ファイル | 種類 | 内容 |
|---|---|---|
| 01-binary-literal.c | 確認 | 0b で始まる書き方で、2進数 0000 0011 を変数に入れる |
| 02-or.c | 確認 | ビット演算子 \| で論理和を求める |
| 03-and.c | 確認 | ビット演算子 & で論理積を求める（予想してから実行） |
| 04-sign-check.c | 確認 | & で最上位ビットだけを取り出し、正の数か負の数かを判定する |
| 05-negate.c | **作成** | 練習問題：* と - を使わずに正負を逆転する |
| 06-shift-left.c | 確認 | 左シフトで値がどう変わるかを確かめる |
| 07-shift-right.c | 確認 | 1111 1100 を符号付きと符号なしで右シフトする |
| 08-led-shift.c | 確認＋改造 | 1 << n で、8個のLEDの点灯状態を1つの変数で操作する |
| 09-mask.c | 確認 | & とマスクで、下位4ビットだけを取り出す |
| 10-xor-diff.c | **作成** | 予備問題：各桁が一致するところだけ0にする |

- **確認**：まずそのまま実行し、ファイル先頭の【まずやること】に書いた表示になるか確かめる。そのあと【やってみよう】で値を変えて試す
- **作成**：「/* ここを書き換える */」の行を自分で書いて完成させる
- **確認＋改造**：実行して確かめたあと、コードを書き足す

## 実行方法

```
cc -Wall -std=c11 -o 02-or 02-or.c
./02-or
```

## 注意

- 05・10は、書き換える前にコンパイルすると「使われていない変数」の警告が出ることがあります。書き換えれば消えます。

- 0b で始まる2進数の書き方は、gcc・clang で使えます（C言語の規格に正式に入ったのはC23から）。
- 04-sign-check.c の %hhd は、1バイトの整数（signed char）を読むための書式です。%d のままだと、隣のメモリまで書き換えてしまいます。
- 07-shift-right.c の負の数の右シフトは、多くの環境で「左端を1で埋める」動作になります。C言語の規格では環境によって結果が変わってよいことになっています。
